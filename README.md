# Signup and Login Page in Django

A simple **Django authentication project** built for learning purposes. It includes user **signup, login, and homepage** functionalities, demonstrating Django’s built-in authentication system and template rendering.

##  Live Website
 [https://rabeeh.pythonanywhere.com/](https://rabeeh.pythonanywhere.com/)

##  Description
This project is a beginner-friendly Django application focusing on user authentication. It covers:
- User registration (signup)
- User login and logout
- Redirecting to a homepage after login
- Django form handling and validations
- Basic front-end using HTML, CSS, and Django templates

It’s deployed on **PythonAnywhere** to showcase how Django apps can be hosted online easily.

##  Tech Stack
- Django (Python Framework)  
- HTML, CSS  
- SQLite (default Django database)  
- Deployed on PythonAnywhere
